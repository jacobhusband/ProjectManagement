## ACIES Scheduler 2.2.1

### What is new
**Projects and pages**
- **Search finds every project.** Typing in the project search now ignores the timeframe, status, deliverable and Needs attention filters, so a search finds projects those filters would hide. Clearing the search brings the filtered view back.
- **Drop emails from new Outlook.** Emails dragged from the new Outlook app onto a page now become email chips that open in Outlook on the web. Attaching emails flags that line as important. Regular pages also get the `/important` command, and the Pages tab gets an Important list.
- **Panel schedule export and receipt editor** are now part of the app.

**Publish**
- **Refresh Excel links or quick print.** When Excel refresh is turned on, Publish asks each time whether to refresh linked Excel tables or just print quickly. It also shows when the newest workbook was saved. Drawings saved after every workbook in their folder are no longer refreshed, and plotting no longer resaves drawings.
- **Save set as.** A "Save set as..." button on a Publish activity lets you choose the folder and file name for the combined PDF. You can use it before, during or after the run.

**CAD tools**
- **XREF asks for drawings right away.** When an XREF run has to wait behind another one, it now asks you to choose its drawings first, so it can run without you.
- **XREF keeps title block images.** Sheets exported from Revit with logos in the title block no longer fail.
- **XREF no longer fails drawings with an empty modelspace.**
- **Clean Drawings** handles missing PDF/image attachments and raster logos. With the next ACIES AutoCAD plugin update, it will also bind XREFs that hold add-on objects such as Express Tools ARCTEXT, and it will stop flagging removed revision clouds/deltas for review.

**Wire Sizer**
- **Copy Shorthand.** This new button copies the feeder in drawing shorthand, for example `(N)1"C., 2#3 H, 1#3 N, 1#8 GND`.

Installing over 2.2.0 keeps your projects and settings.
