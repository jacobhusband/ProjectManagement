## ACIES Scheduler 2.5.1

### Transfer app data between computers

- Export projects, notes, timesheets, checklists, templates, preferences, and files stored inside the app as one ZIP from Settings → Maintenance.
- Import a transfer ZIP on another computer after confirmation. Import saves a recovery copy before replacing data and retains that computer's API key.
- Exports exclude API keys and account credentials. External project folders, drawings, and linked files still need to be moved separately.

### Simpler deliverable dates

- Deliverables now use one due date throughout project cards, editing, filters, and reports.
- Existing paired dates migrate to the firm deadline when present, otherwise the soft date. The original dates remain in the saved history.
- Due-date controls on project cards stay close to the date text.

### Setup and navigation

- Setup includes a recommended AutoCAD plugin step and an optional guided walkthrough for creating a project, adding a deliverable, and finding Publish.
- The header keeps the Mechanical, Electrical, and Plumbing discipline controls directly accessible. Google account sign-in controls have been removed.

### File dialogs

- App-owned Open, Save As, and folder-selection dialogs now receive focus and block app interaction until selection or cancellation. This prevents activity cancellation from leaving an unattended file picker open.

Installing over 2.5.0 preserves existing projects and settings; paired deliverable dates migrate to the single-date format described above.
