## ACIES Scheduler 2.3.0

### What is new
**Deliverables**
- **Select several deliverables at once.** Ctrl-click adds or removes a row or card from the selection, and Shift-click selects a range. With several selected, the command line can pin, unpin or set the status of all of them together.

**CAD tools**
- **New Backgrounds (formerly XREF).** It now finds the newest Arch version of each background your discipline's DWGs reference, using the dated package folders, and only asks you to pick files in Arch when it finds none.
- **XREF (formerly Repair XREF Paths) lists every XREF in every drawing.** Each XREF gets its own row with an In Drawing column, so you can change one drawing without changing the others. You can type a path (relative paths allowed), set one path on several rows at once, and filter by text or show only XREFs that are not found. The scan shows its progress.
- **Nested XREFs are repaired where they live.** A nested XREF is listed under its parent DWG, and its new path is saved in that parent, so AutoCAD no longer drops it the next time the parent loads.
- **Clean Drawings handles more broken attachments.** A PDF underlay that points past the last page of its PDF, or an image whose file is empty, used to fail the whole job. Both are now removed from the working copy and listed in the report, like a missing file.

Installing over 2.2.2 keeps your projects and settings.
