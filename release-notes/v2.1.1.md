## ACIES Scheduler 2.1.1

### Add your own Gemini API key
This release no longer includes a shared Gemini API key. The installer is public, so anyone could unpack it and read a key stored inside. The AI features now use only the key you enter yourself.

- If you already saved your own key in Settings, nothing changes for you.
- If the AI features say the key is missing after you update, open Settings and paste your own key. The app has a short guide and a link for getting a free key from Google AI Studio.

### Also in this release
- Release pages now carry written notes, like this one.
- After each release is published, it is installed and started on clean Windows machines (Windows Server 2022 and 2025, with and without the WebView2 Runtime) as an automatic check. From this release on, that check also confirms the installer carries no API key.

Installing over 2.1.0 keeps your projects and settings.
