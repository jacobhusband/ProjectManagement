## ACIES Scheduler 2.2.0

### What is new
**Setting up a new PC**
- **AutoCAD plugin offer.** If AutoCAD is installed but none of the ACIES plugins are, the app now offers to install them at launch, or right after first-run setup. Choose "Not right now" to be asked again next time, or "Do not ask again" to stop. Anyone who already has an ACIES plugin is left alone.
- **Plot style check.** Publish DWGs now checks for `510-monochrome.ctb` before starting and says where to put it if it is missing, instead of failing partway through.
- **Update checks are gentler on GitHub.** Release information is kept for a few minutes, so a rate limit no longer shows up as "No published releases found". If GitHub is limiting requests, the app says so.
- **Wire Sizer no longer needs the internet to look right.** Its styling is built into the app instead of loaded from a website.

**Working in the app**
- **Work locally.** A per-project switch (in the command dock) points a project's tools and "Open project folder" at your Local Projects copy instead of the server folder. Switching it on needs a local copy; if there is none, the app tells you how to make one.
- **Safer local copies.** Only the discipline and Xrefs folders are ever replaced or removed when copying or syncing. Arch, Photos, RFI and Documents only gain missing files.
- **Place published sets.** After Publish DWGs finishes, you can move the combined PDF into an existing or new issue folder under the project's PDF folder, or keep it in the output folder.
- **Project page search.** Cleaned up leftover search highlighting in project pages.

**CAD tools**
- **Layer scans no longer get stuck.** A drawing that opens with unresolved references used to leave AutoCAD waiting on a prompt. Those drawings are now read in their own session, and the scan quits without saving.
- **Excel refresh checks for open drawings.** If the drawing is open in AutoCAD, the refresh is skipped with a clear message instead of hanging in a hidden window. Drawings with no linked Excel content are no longer resaved.
- Xref path and plot scripts no longer change AutoCAD's file dialog settings.

Installing over 2.1.1 keeps your projects and settings.
