## ACIES Scheduler 2.1.0

### Before you install
- Windows 10 (version 1607 or newer) or Windows 11, 64-bit. Windows 7, 8 and 8.1 are not supported, and Setup now says so instead of installing an app that cannot start.
- Setup installs Microsoft's WebView2 Runtime if your PC does not have it. That needs an internet connection the first time.
- The CAD tools need AutoCAD 2020 or newer. Classic Outlook is needed for the email tools, and Excel for `.xls` panel schedules.
- The AI features use your own Gemini API key. The app walks you through creating one at first run, and you can change it in Settings.

### What is new
**Installing and first run**
- **Publish DWGs works without Python.** The PDF merge, layer strip, shrink and paper-size steps are now built into the app. Before, they needed Python and PyMuPDF installed separately, and the tool failed on any PC without them.
- **AutoCAD is found automatically.** The app reads Autodesk's registry entries, so any release (including 2027) on any drive is listed. The picker used to look only in `C:\Program Files` for 2022 to 2026.
- **A clear message instead of a blank window.** If the WebView2 Runtime or .NET Framework 4.6.2 is missing, the app now says so and links to the download.

**Working in the app**
- **Activity history.** Finished tool runs are saved and stay reachable from the header and the tray.
- **Activity lanes.** Runs for the same project wait their turn, other projects run at the same time, and Freeze / Thaw and Clean Xrefs run one at a time.
- **Deliverable due dates.** The soft date shows until it passes, then the hard date takes over.
- **Xref preparation.** If binding fails, it is retried with prefixed names, and a reference that cannot be bound faithfully stays attached as an XREF.
- Layout and style refinements across the project and deliverables views.
