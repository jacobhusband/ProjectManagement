## ACIES Scheduler 2.5.0

### What is new

**Clean Drawings**
- Clean Drawings no longer needs the ACIES AutoCAD plugin. The app now includes the parts of the plugin it uses, so selecting AutoCAD Core Console in Settings is enough.
- Clipped PDF underlays keep their clip and layer states after cleanup.

**AutoCAD tools**
- Publish, Freeze/Thaw, Clean XREFs, and XREF path repair no longer leave your AutoCAD settings changed after they run (for example SECURELOAD, CMDDIA, BACKGROUNDPLOT, and PROXYSHOW).
- When one of these commands fails, the error now includes AutoCAD's own last message, and the app log records more of AutoCAD's output.

**Projects**
- Open Latest Arch Set skips specialty and vendor PDFs (furniture, security, specs, surveys, shop drawings, other disciplines) and prefers complete architectural sets over single sheets. With a Gemini API key it ranks candidates by file and folder names only, never PDF contents.

**Expenses**
- Exported expense sheets are signed with your name from Settings. Earlier versions put the same fixed name on every user's expense sheet.

Installing over 2.4.0 keeps your projects and settings.
