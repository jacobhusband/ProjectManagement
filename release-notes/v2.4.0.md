## ACIES Scheduler 2.4.0

### What is new

**AutoCAD plugins**
- Support for the combined ACIES AutoCAD plugin, with a Commands dialog to search commands and switch individual commands or whole groups on or off. AutoCAD applies saved choices the next time it starts.
- Installing the combined plugin removes the older per-plugin bundles to prevent duplicate commands. Existing command choices are kept during updates.
- Clean Drawings recognizes both the combined plugin and older standalone installations.

**Help and workspace**
- Search help topics from the Help dialog, and open tool and plugin help in a dedicated dialog with command descriptions.
- Updated workspace layouts, project filters, onboarding, and tool presentation.

**Project files**
- Work Locally ignores tool-generated by-products and records file baselines when copying a project, improving later synchronization.
- XREF path handling improvements.

Installing over 2.3.0 keeps your projects and settings.
