## ACIES Scheduler 2.5.3

### New-user portability & packaging fixes

- Bundled `title24` assets and the `CleanCAD-bin` worker in both PyInstaller specs so Clean Drawings and Title 24 work on clean installs.
- Added COM initialization/cleanup for Word/Excel automation and `openpyxl` fallbacks when Excel is unavailable during panel schedule sync and conflict highlighting.
- Improved Clean Drawings plot-style table checks, AutoCAD version detection on custom install directories, fresh database read/delete handling, and user-settings Gemini API key resolution.
- Hardened CAD and PDF helper scripts (`PrepareXrefs` / `StripRefPaths`, `PlotDWGs`, `ManageLayersDWGs`, `ManageXrefPathsDWGs`, `removeXREFPaths`, `merge_pdfs`, `detect_pdf_size`, `shrink_pdf`) for multi-targeted AutoCAD .NET 4.8 / .NET 8 support, Python discovery, and shallow project folder paths.
- Removed render-blocking Google Fonts from Wire Sizer and updated Wire Sizer UI.

### Quality-of-life & UI improvements

- Added sortable list view headers (`ID`, `Project`, `Deliverable`, `Due`, `Status`), Partial Print dock entry, and default Freeze/Thaw wildcard pattern inputs in Settings.
- Improved toast notifications, timesheet project picker search and project-only row creation, timesheet save queue serialization/debouncing, local copy folder routing when Work locally is enabled, and PyWebView API startup readiness.
- Collapsed timesheet storage diagnostics under `<details>` and updated Help copy.
