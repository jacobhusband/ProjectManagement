Default freeze patterns
Wildcards (* and ?) matched against layer names. Comma- or semicolon-separated. When set, the tool skips the manual layer dialog and freezes any layer that matches. Leave empty to keep the manual dialog.
Default thaw patterns
Same syntax as freeze patterns. Matched layers are thawed.

Help

Projects

The Projects tab is where you track every active job. Each project holds a set of deliverables, due dates, and status flags that drive the rest of the app.

Creating & editing

  • Add a project: use the New button in the toolbar.
  • Edit: click a project card or row to open the edit dialog. You can rename it, change dates, add/remove deliverables, and adjust status.

Merge similar projects is available in Settings > Actions when duplicate cleanup is needed.

Status values

Setting a deliverable status helps keep work organized and shows where that deliverable stands at a glance.

  • Waiting: something is preventing work from proceeding, such as engineer coordination or background information being prepared. It is not explicitly on hold.
  • On hold: explicitly paused, usually waiting on a client or stakeholder.
  • Pending Review: finished on your end, awaiting QA or check.
  • Complete: deliverable is done but not yet sent out.
  • Completed (by others): deliverable was completed by someone else.
  • Delivered: final package has been sent.

View modes & filters

  • Card and list view: both modes are available ways to view workload.
  • Pin a project or deliverable: click the pin icon on the card. Pinned items stay at the top across sessions.
  • Status filters: click a status chip at the top of the panel to filter. On hold is hidden by default; toggle it on to bring those projects back.
  • Search enables quick location of projects using relevant keywords.

Deliverables

Every project has one or more deliverables with their own due dates and status. Use the deliverable notepad to collect items from multiple projects and export them to Excel when building a combined scope or invoice.

Notes

The Notes tab is for free-form writing. Each page has its own tab in the sidebar and autosaves as you type.

Pages

  • Create: click + New page in the sidebar to add a tab for each topic (meeting logs, standards references, etc.).
  • Delete: hover a page tab and click the X icon. Deletes are permanent after confirmation.
  • Autosave: content saves as you type — there is no save button.

Searching

  • The search box at the top of the Notes tab searches the active page. Results show the matching paragraphs so you can jump straight in.
  • Click a result to scroll the textarea to that paragraph and select the matching text.

Scratchpad

The pencil icon in the app header opens a quick scratchpad for unsorted notes that don't need their own page.

Tools

The Tools tab is where you run bundled utilities and AutoCAD plugins. Tools are grouped into cards; click a card's chevron to expand its details.

Running a tool

  • Most tools run immediately when you click their action button. Progress and logs appear on the card.
  • If a process is running, an Abort Process button appears in the toolbar — use it if a tool hangs or needs to be cancelled.

AutoCAD Plugins

  • Installation: the first time you run a plugin, the app installs it into your AutoCAD profile. If prerequisites are missing you'll see an install prompt.
  • Version selection: when multiple AutoCAD versions are installed, the app asks which one to target.
  • Uninstall: available from the plugin card menu. This removes the plugin from AutoCAD but does not delete your drawings.

Updates

Use the refresh icon next to the version label in the app header to check for tool and app updates. When an update is available, an Update button appears — click it to install the latest bundle.

Timesheets

The Timesheets tab is a weekly grid for logging hours and expenses against your projects.

Navigating weeks

  • Use Previous and Next to move between weeks, or Current week to jump back to today.
  • The displayed range updates the header and determines what's saved and exported.

Logging time

  • Add project entry: pick an existing project and log hours against it — the entry is linked so the project's status reflects the work.
  • Add manual entry: use this for work that isn't tied to a tracked project (admin, training, etc.). You can free-type the label.
  • Edit any cell to update hours; totals at the bottom recalculate automatically.

Exporting

Click Export Excel to save the current week as an .xlsx file using the built-in template. The output matches the format the accounting team expects.

Expenses

  • Add expense: attach a project and amount. You can attach a photo of the receipt — click the thumbnail to preview it full-size.
  • Expenses export alongside hours when you export the week.

Misc

Global controls are available from the app header.

  • Settings: the cogwheel opens app preferences and actions.
  • Theme: the theme toggle switches between light and dark mode.
  • Scratchpad: use the scratchpad for quick unsorted notes that do not need a notebook page.
